# Deprince Foodmart Admin Guide

This is a simple guide for the shop owner. You do not need technical knowledge to use it.

## 1. Log in to the admin area
- Open the site dashboard.
- Go to the login page.
- Use the admin email and password from the environment file.
- If you are using a live deployment, change the default password immediately after the first login.

## 2. Add a product
1. Go to Products.
2. Click Add Product.
3. Enter the product name, price, old price, unit, and category.
4. Upload a product image if available.
5. Click Save.

## 3. Change a product price
1. Open Products.
2. Find the product.
3. Click Edit.
4. Update the price.
5. Save changes.

## 4. Change a banner
1. Go to Banners.
2. Click Add Banner or Edit on an existing one.
3. Upload an image (up to 3 MB) or enter a public image URL, then edit the headline, subtext, button text, and link.
4. Set the sort order and active status.
5. Save.

Image uploads need Cloudinary to be configured by the person who set up the website. The existing homepage banner works without this; it can also be replaced by entering a public image URL.

## 5. Write a blog post
1. Open Blog.
2. Click Add Post.
3. Add title, excerpt, cover image, and full article text.
4. Choose Draft or Published.
5. Save.

## 6. Update WhatsApp number
1. Open Settings.
2. Update the WhatsApp number field.
3. Save settings.
4. Test the link before going live.

## 7. Update business info
In Settings, you can edit:
- business name
- phone number
- email
- address
- opening hours
- social media links
- checkout greeting
- logos

## 8. Basic daily routine
- Add new products when stock arrives.
- Update prices when suppliers change rates.
- Post a short blog update once or twice a week.
- Keep at least one active banner on the homepage.
- Check the WhatsApp number and office contact details often.
